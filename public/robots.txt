# `/badge/builder/` and `/badge/builder?` block the old per-login builder pages and
# every builder state (an entity, a badge, a style); the bare `/badge/builder` and
# `/badge/gallery` stay crawlable. `/api/badge/v3/` is the builder's data, not a page.
# Google takes the longest matching rule, so `Disallow: /api/badge/v3/` wins over
# `Allow: /api/badge/` and `Disallow: /badge/builder?` over `Allow: /`; the order
# below gives first-match parsers the same answer.
#
# Crawl-delay is the pause, in seconds, between two requests from one crawler.
# Bing, Anthropic and Ahrefs honour it; Google, Apple, Amazon and Yandex ignore
# it; the others don't say. 2 seconds caps a crawler that honours it at about
# 43,000 pages a day. Crawlers that ignore it need a rate limit outside this file.
#
# In every group the specific rules come first and `Allow: /` last, so parsers
# that take the first matching rule read it the same way as RFC 9309 parsers.
#
# Content-Signal repeats the site-wide usage signal for the AI groups: a crawler
# that matches a named group never reads the `*` groups.
